# Spilløkka

Vi låner **løkka** fra tekstbaserte nettleserspill som nordicmafia.no og **produksjonen** fra Hay Day – og setter alt i en postapokalyptisk verden. Spørsmålet for hver byggekloss er: **hvordan blir dette visuelt, mobilvennlig og overlevelses-aktig hos oss?**

## Byggeklossene

| Mekanikk | Hvordan det funker i forbildene | Idé for oss |
|---|---|---|
| **Handlinger med nedkjøling** | Velg en handling, vent, prøv igjen (nordicmafia) | Rote i ruiner, jakte, reparere – trykk på bygg i bosetningen |
| **Sjanse for å lykkes** | Risiko vs belønning (nordicmafia) | Ekspedisjoner kan feile – du kommer hjem skadet eller tomhendt |
| **Produksjonskjeder** | Hvete → mel → brød (Hay Day) | Skrap → deler → verktøy, regnvann → renset vann |
| **Tapping / clicking** | Klikk for å tjene litt, oppgrader for å tjene mer (Cookie Clicker) | Tapp skraphaugen mens du venter. Oppgraderinger gjør tappene verdt mer. |
| **Rank / nivå** | Erfaring gir nye muligheter | Bosetningen vokser fysisk når du går opp i nivå |
| **Samspill** | Allianser, hjelpe andre (begge) | Bosetninger slår seg sammen, deler ressurser, bygger felles prosjekter |
| **Hjelpe hverandre** | Bryte ut andre fra fengsel (nordicmafia), hjelpe naboer (Hay Day) | Pleie strålingssyke spillere, sende forsyninger |
| **Handel** | Veikiosk / markedsplass (Hay Day) | Handelspost: byttehandel med andre spillere |
| **Utforsking** | Reise mellom byer | Ekspedisjoner ut i ødemarka, nye soner låses opp |

## Kjerneløkka (utkast)

```
Sjekk inn → høst ferdige handlinger → start nye → tapp litt mens du er der
    ↑                                                        ↓
    └── vent (varsel) ←── lås opp nytt ←── oppgrader bygg / gå opp i nivå
```

## Fallgruver vi bør unngå

- **Pay-to-win** – ødelegger samspillet
- **For harde tap** – nye spillere som mister alt dag 2 kommer aldri tilbake
- **Tomt spill** – multiplayer trenger mange spillere. Hva er gøy med bare 5 spillere?
- **For lange ventetider tidlig** – de første 10 minuttene må være raske og gøye (tapping hjelper her)
- **Tapping som blir kjedelig** – bør være en krydder, ikke hovedretten
